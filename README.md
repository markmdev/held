# Held

PayPal holds the client's money while a freelancer works, Claude checks the delivered work against the brief both sides agreed, and the freelancer is paid the minute it passes.

Built for the PayPal AI Hackathon on 12 November 2026, from an empty repo. The full write-up comes before submission.

## Run it

```sh
npm install
cp .dev.vars.example .dev.vars   # fill in the keys
npm run db:migrate:local
npm run dev
```
